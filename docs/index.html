Claude スキル帳

Claude Code で使えるスキルを、日本語で「どんな時に使うか」から探せる一覧です。キーワードやカテゴリで絞り込めます。

よく探すこと：

新しいスキルを追加したら

  1. このリポジトリで Claude Code を開くと、新しいスキルが自動で見つかり、一覧に追加されます。
  2. 「スキル一覧を更新して」と頼むと、日本語の解説を書いて一覧を作り直します（/update-skill-catalog）。
  3. GitHub に push すると、一覧ページも自動で作り直されます。
